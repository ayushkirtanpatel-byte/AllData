# Smart City Energy Management Project

## 📌 Overview

This project focuses on analyzing smart city energy consumption using SQL and visualizing insights using Power BI Dashboard.

## 🗂️ Project Files

* SMART_CITY.sql (Database + Queries)
* SmartCityEnergy Dataset (Excel/CSV)
* Power_Bi_Dashboard.pbix (Dashboard)
* README.md (Documentation)

## 🛠️ Tools Used

* MySQL (Data Analysis)
* Power BI Desktop (Visualization)

## 📊 Dashboard Features

* KPI Cards (Total Consumption, Peak Usage, Outage, Cost)
* Monthly Energy Consumption Trend (Line Chart)
* Energy Usage by Consumer Type (Bar Chart)
* Zone-wise Energy Distribution (Map)
* Weekday vs Weekend Analysis
* Interactive Filters (Zone, Consumer Type, Date)

## 🔍 Key Insights

1. Industrial sector consumes the highest energy.
2. Central zone has high overall energy usage.
3. Faulty meters lead to higher outage time.
4. Energy consumption is higher on weekdays.
5. Tariff rates affect total energy cost.

## 🚀 Conclusion

This project helps identify energy usage patterns and inefficiencies in a smart city environment using data-driven analysis.
