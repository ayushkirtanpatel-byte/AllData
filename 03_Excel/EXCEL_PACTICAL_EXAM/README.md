# Excel Dashboard — Practical Exam

## Overview
An Excel dashboard project focused on data preparation, analysis, PivotTables, formulas, charts, and interactive dashboard controls.

## Work Performed
- Imported and organized the raw dataset in a Database sheet
- Checked missing values, data types, and duplicate records
- Created PivotTables using SUM and COUNT calculations
- Used VLOOKUP, INDEX-MATCH, IF, and nested formulas
- Built charts from PivotTable data
- Added slicers and a timeline for interactive filtering
- Organized the workbook into Database, Pivot Table, Dashboard, and Statistics sheets
