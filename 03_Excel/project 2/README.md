# Excel Analysis Project 2

## Overview
An Excel analysis project focused on customer, sales, and regional analysis, with statistical tools, What-If Analysis, PivotTables, and a dashboard.

## Analysis Tasks
- Identify the top 10 customers by total purchase
- Perform linear equation analysis using the Data Analysis ToolPak
- Use What-If Analysis for management and deductible scenarios
- Track monthly sales growth with directional indicators
- Create a scenario summary sheet
- Calculate total purchases with SUMIF
- Create timestamps with NOW
- Identify high-value people using INDEX and MATCH
- Generate descriptive statistics with the Data Analysis ToolPak
- Create PivotTables for month vs. sales, product vs. profit, and region vs. sales
- Summarize results in a dashboard
