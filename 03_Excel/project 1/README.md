# Fundamental Booster — Excel Project

## Overview
An Excel fundamentals project covering student analysis, sales lookups, employee information retrieval, and common spreadsheet functions.

## Analysis Tasks
- Classify student grades
- Calculate total and average student marks
- Count students achieving at least 60 marks
- Identify students scoring 80+ in Mathematics and Science
- Practice text formatting and case-conversion functions
- Find product prices from product IDs
- Apply MIN and MAX functions
- Find employee salary from employee ID
- Retrieve employee training dates using ID-based lookups
