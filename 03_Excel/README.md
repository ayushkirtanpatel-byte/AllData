# 03_Excel — Excel Analysis & Dashboard Projects

This directory contains Excel spreadsheets, dashboards, formulas, and analysis projects demonstrating data manipulation, lookup functions, What-If scenario analysis, and dynamic visualization in Microsoft Excel.

## Projects Summary

| Project | Description | Technologies |
|---|---|---|
| `project 1/` | Fundamental booster project performing student grade classification, text functions (UPPER/LOWER), average/total formulas, and VLOOKUP price extractions. | Microsoft Excel |
| `project 2/` | Sales analyzer project identifying top 10 customers, linear regression modeling, What-If scenario summary sheets, and SUMIFS aggregation formulas. | Microsoft Excel |
| `final project/` | Advanced Excel analysis project utilizing slicers, timelines, date/time functions, What-If Goal Seek analysis, and INDEX/MATCH lookups. | Microsoft Excel |
| `EXCEL_PACTICAL_EXAM/` | Portfolio dashboard built on formatted databases with duplicate record checking formulas and visual KPI cards. | Microsoft Excel |
