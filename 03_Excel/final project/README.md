# Excel Final Project

## Overview
An Excel analysis and dashboard project demonstrating date/time functions, filtering, conditional formatting, what-if analysis, customer analysis, lookup functions, PivotCharts, slicers, and timelines.

## Key Tasks
- Calculate real-time date and time values
- Use the FILTER function to return multiple values
- Apply conditional formatting with icons and arrows
- Create timestamps with the NOW function
- Perform What-If Analysis using Scenario Management and Goal Seek
- Identify high-value customers with IF logic
- Create slicers and timelines
- Find frequently purchased products using INDEX and MATCH
- Compare names across columns
- Create PivotCharts
- Build an interactive dashboard using PivotTables, slicers, and timelines
