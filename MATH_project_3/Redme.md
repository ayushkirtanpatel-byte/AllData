# 📊 Health Data Analysis Project

## 🎯 Objective
Analyze a synthetic health dataset using Inferential Statistics and Statistical Testing techniques.

---

## 📂 Dataset
Dataset contains:

- Age
- Age Group
- Weight
- Gender
- Region
- Smoking Status
- Exercise Frequency
- BMI
- Blood Pressure
- Diabetes
- Hypertension
- Cholesterol Level
- Glucose Level

---

## 🧠 Statistical Concepts Covered

### 1. Inferential Statistics
Used to make conclusions about a population using sample data.

### 2. Hypothesis Testing
Used to determine whether a claim is supported by data.

### 3. Confidence Interval
Provides a range of values likely to contain the population parameter.

### 4. p-value
Determines statistical significance.

### 5. Type I & Type II Errors
False Positive and False Negative errors.

### 6. Statistical Tests
- t-Test
- Chi-Square Test
- ANOVA

### 7. Covariance
Measures joint variation of variables.

### 8. Correlation
Measures strength and direction of relationship.
