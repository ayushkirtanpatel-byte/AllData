# 07_EDA — Exploratory Data Analysis & Preprocessing Projects

This directory contains Exploratory Data Analysis (EDA), data cleaning, data preprocessing, and feature engineering projects preparing real-world datasets for machine learning models.

## Projects Summary

| Project | Description | Technologies |
|---|---|---|
| `DP_PROJECT_1/` | Customer churn preprocessing and EDA project ingesting data from CSV, JSON API payloads, and SQLite databases for profiling and exploratory analysis. | Python, Jupyter Notebook, SQLite, Pandas |
| `DP_PROJECT_2/` | Healthcare data preprocessing project evaluating multiple missing value imputation techniques and statistical outlier treatments (IQR/Z-score) on patient records. | Python, Jupyter Notebook, Pandas, Scikit-Learn |
| `DP_practical.Exam/` | Customer purchase propensity pipeline featuring multi-source data loading (CSV, JSON, SQL DDL, API), missing data imputation, outlier treatment, and feature engineering pipelines. | Python, Jupyter Notebook, Pandas, Scikit-Learn |
| `DP_Final_project/` | Holistic Data Preparer project: 8-day end-to-end data preprocessing and feature engineering pipeline on customer credit risk data for ML loan default prediction. | Python, Jupyter Notebook, Pandas, Scikit-Learn |
