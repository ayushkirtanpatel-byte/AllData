# Data Analytics & Programming Repositories

This root repository serves as an entry point for 7 individual topic repositories covering Python programming, SQL database manipulation, Excel financial and data analysis, Power BI business intelligence dashboards, business case studies, mathematical & statistical modeling, and exploratory data analysis (EDA).

---

## Individual Topic Repositories

### `python/`
Python programming repository focusing on core concepts such as OOP, module design, data structures, control flow, file handling, interactive user inputs, NumPy array manipulation, and Matplotlib/Seaborn visualization utility tools.

### `sql/`
SQL database repository demonstrating relational schema design, DDL/DML, aggregations, window functions, complex JOINs, subqueries, and data cleaning routines.

### `excel/`
Excel analysis repository covering advanced formulas (VLOOKUP, INDEX/MATCH, SUMIFS), What-If analysis, scenario management, conditional formatting, pivot tables, and dashboard design.

### `powerbi/`
Power BI repository featuring star-schema data modeling, DAX measure creation, interactive visualizations, retail sales tracking, academic performance analytics, and executive reports.

### `business_case_studies/`
Business case studies repository combining multi-source data (SQL, Power BI, Excel) to solve domain-specific business challenges in retail sales and smart city energy management.

### `mathematics/`
Mathematics and statistics repository covering descriptive and inferential statistics, probability distributions, theoretical vs. empirical testing, linear algebra (matrix decomposition, PCA, LDA), and hypothesis testing.

### `eda/`
Exploratory Data Analysis repository involving end-to-end data cleaning, preprocessing pipelines, multi-source ingestion (CSV, JSON, SQL, APIs), outlier detection, feature engineering, missing data imputation, and statistical distribution exploration.
