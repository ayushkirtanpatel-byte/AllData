# Data Analytics & Programming Portfolio

Welcome to my Data Analytics & Programming Portfolio repository. This repository showcases a comprehensive collection of projects covering Python programming, SQL database manipulation, Excel financial and data analysis, Power BI business intelligence dashboards, business case studies, mathematical & statistical modeling, and exploratory data analysis (EDA).

---

## Repository Structure

### 01_Python
Python programming projects and practice focusing on core concepts such as OOP, module design, data structures, control flow, file handling, interactive user inputs, NumPy array manipulation, and Matplotlib/Seaborn visualization utility tools.

### 02_SQL
SQL, database, querying, and data transformation projects demonstrating relational schema design, DDL/DML, aggregations, window functions, complex JOINs, subqueries, and data cleaning routines.

### 03_Excel
Excel analysis, dashboards, and spreadsheet projects covering advanced formulas (VLOOKUP, INDEX/MATCH, SUMIFS), What-If analysis, scenario management, conditional formatting, pivot tables, and dashboard design.

### 04_PowerBI
Power BI dashboards and business intelligence projects featuring star-schema data modeling, DAX measure creation, interactive visualizations, retail sales tracking, academic performance analytics, and executive reports.

### 05_Business_Case_Studies
Business problems, case studies, analysis, and recommendations combining multi-source data (SQL, Power BI, Excel) to solve domain-specific business challenges in retail sales and smart city energy management.

### 06_Mathematics
Mathematics, statistics, probability, and related academic projects covering descriptive and inferential statistics, probability distributions, theoretical vs. empirical testing, linear algebra (matrix decomposition, PCA, LDA), and hypothesis testing.

### 07_EDA
Exploratory Data Analysis projects involving end-to-end data cleaning, preprocessing pipelines, multi-source ingestion (CSV, JSON, SQL, APIs), outlier detection, feature engineering, missing data imputation, and statistical distribution exploration.

## Overview of Projects by Directory

### 01_Python
- **Data Collector (`datacollector.py`)**: Interactive CLI script collecting personal information with type and memory address inspection.
- **File Operator (`fileoperetor.py`)**: Object-oriented journal management system with file I/O operations.
- **Modular Utilities (`modular.py`)**: Datetime, timer, UUID generation, and math module wrapper functions.
- **NumPy Project (`numproject.py`)**: Interactive NumPy array creation and multi-dimensional analysis tool.
- **OOP Wrapper (`oopwraper.py`)**: Class inheritance hierarchy demonstrating Object-Oriented Programming principles.
- **Data Visualizer (`visualizer.py`)**: Generic dataset loader and Matplotlib/Seaborn visualization wrapper.

### 02_SQL
- **Data Digger Project (`data_digger project.sql`)**: Database DDL/DML setup for client and transaction tracking.
- **Data Transform (`data_transform.sql`)**: Data cleaning and transformation queries for customer database tables.
- **Final Project SQL (`final_project.sql`)**: Multi-table relational schema for student course enrollments and instructors.
- **Smart Library Management System (`PRCTICAL/`)**: Complete MySQL database system covering CRUD, JOINs, aggregations, window functions, and CASE expressions.

### 03_Excel
- **Fundamental Booster (`project 1/`)**: Student grade classification, formula calculations, text manipulation, and lookup functions.
- **Data Analyzer (`project 2/`)**: Top customer analysis, linear regression modeling, scenario summary sheets, and SUMIFS formulas.
- **Advanced Excel Final Project (`final project/`)**: Slicers, timelines, date/time operations, What-If goal seek analysis, and INDEX/MATCH lookups.
- **Excel Practical Dashboard (`EXCEL_PACTICAL_EXAM/`)**: Full Excel dashboard built on formatted databases with duplicate check formulas.

### 04_PowerBI
- **Multi-Source Sales Project (`PROJECT_1/`)**: Multi-month sales data combined via Power Query with Web API HTML integration.
- **Sales & Returns Star Schema (`PowerBi PROJECT_2/`)**: Fact and dimension table modeling linking sales, customers, products, regions, and returns.
- **DAX Sales Analysis (`powerBi PROJECT_3/`)**: Advanced DAX calculations and data modeling across sales and product dimensions.
- **Executive Sales Dashboard (`Final_Project/`)**: Star schema data model delivering KPI cards, return analysis, and regional trends.
- **Student Performance Analytics (`Ayush_PRCTICAL EXAM/`)**: Multi-table dashboard analyzing scores, attendance trends, and behavioral patterns.

### 05_Business_Case_Studies
- **Retail Sales Analysis Case Study (`case study_1/`)**: Analysis of 500 retail transactions combining SQL aggregation queries and an interactive Power BI dashboard.
- **Smart City Energy Management (`Smart_city/`)**: SQL database setup and Power BI dashboard for analyzing smart city energy consumption and outage metrics.

### 06_Mathematics
- **Household Income Demographics (`MATH_Project_1/`)**: Descriptive statistics, dispersion measures, skewness, kurtosis, and income distribution visualization.
- **Expectation Decider (`MATH_project_2/`)**: Empirical vs. theoretical probability modeling student exam performance.
- **Health Inferential Statistics (`MATH_project_3/`)**: Hypothesis testing (t-test, Chi-Square, ANOVA), confidence intervals, and p-value evaluation.
- **Probability Distributions & Spread (`MATH_project_4/`)**: Transaction data modeling using Bernoulli, Binomial, Log-Normal, Power Law, and Poisson distributions.
- **Linear Algebra Student Performance (`MATH_project_5/`)**: Student performance vectors, matrix decompositions (LU, SVD), PCA, and LDA.
- **Math & Advanced Statistics Exam (`MATH_PRACTICAL_EXAM/`)**: Theory and practical Jupyter notebooks analyzing 5,000 student score records.

### 07_EDA
- **Customer Churn Preprocessing (`DP_PROJECT_1/`)**: Preprocessing, EDA, and data profiling on a customer churn dataset across CSV, JSON, and SQLite.
- **Healthcare Data Cleansing (`DP_PROJECT_2/`)**: Missing value imputation and statistical outlier treatment on 700 patient records.
- **Purchase Propensity Pipeline (`DP_practical.Exam/`)**: Feature engineering pipeline integrating CSV, JSON, SQL DDL, and API data sources.
- **Holistic Data Preparer Credit Risk (`DP_Final_project/`)**: End-to-end 8-day preprocessing pipeline preparing customer credit risk data for machine learning models.
