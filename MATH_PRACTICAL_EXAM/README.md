# 📊 Mathematics & Advanced Statistics Project

## 👨‍🎓 Practical Exam: Theory + Practical

### 📌 Project Overview

This project is based on a student performance dataset (`students_scores_.csv`) containing approximately 5000 records. The objective is to perform statistical analysis, probability calculations, data visualization, and basic linear algebra operations using Python.

# 📂 Dataset Information

| Column Name | Description |
|------------|-------------|
| Student_ID | Unique Student Identifier |
| Age | Student Age |
| Math_Score | Mathematics Marks |
| Science_Score | Science Marks |
| English_Score | English Marks |
| Hours_Studied | Number of Study Hours |
| Pass_Fail | Pass (1) / Fail (0) Status |

# 💻 Part B – Practical Implementation

All practical tasks were implemented using Python libraries:

- Pandas
- NumPy
- Matplotlib
- SciPy

## Step 1: Measures of Central Tendency & Dispersion

- Calculated Mean, Median and Mode of Math_Score.
- Calculated Range, Variance and Standard Deviation of Science_Score.

## Step 2: Probability Basics

- Calculated Probability of Passing.
- Created Contingency Table between Pass_Fail and Hours_Studied > 5.
- Calculated Conditional Probability P(Pass | Hours_Studied > 5).

## Step 3: Distribution & Visualization

- Plotted Histogram of Math Scores.
- Added Normal Distribution Curve.
- Calculated Skewness and Kurtosis.
- Generated Q-Q Plot for English Score.

## Step 4: Linear Algebra Mini Task

- Created Math and Science Score Vectors.
- Calculated Dot Product.
- Calculated L1 and L2 Norms.
- Calculated Angle Between Vectors.
