# 01_Python — Python Programming Projects

This directory contains Python programming projects and practice scripts demonstrating core and advanced Python concepts, including Object-Oriented Programming (OOP), module design, file I/O operations, interactive data collection, NumPy array manipulations, and dataset visualization utilities.

## Projects Summary

| Project | Description | Technologies |
|---|---|---|
| `datacollector.py` | Interactive CLI application collecting personal details with data type inspection and memory address tracking (`id()`). | Python (CLI, Built-ins) |
| `fileoperetor.py` | Journal management application implementing OOP concepts, file append/read operations, and error handling for file I/O. | Python (OOP, File Handling) |
| `modular.py` | Utility suite providing interactive menus for datetime formatting, countdown timers, UUID generation, and mathematical functions. | Python (`datetime`, `time`, `random`, `uuid`, `math`) |
| `numproject.py` | Interactive NumPy utility for creating 1D, 2D, and 3D arrays, indexing, slicing, and computing statistical aggregations. | Python, NumPy |
| `oopwraper.py` | Class hierarchy demonstrating OOP principles including inheritance, method overriding, and constructor chaining with `super()`. | Python (OOP, Inheritance) |
| `visualizer.py` | Dataset visualizer class for loading CSV files, displaying basic statistics, and rendering charts via Matplotlib and Seaborn. | Python, Pandas, NumPy, Matplotlib, Seaborn |
