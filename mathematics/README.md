# 06_Mathematics — Mathematical & Statistical Analysis Projects

This directory contains mathematics, statistics, and probability projects evaluating theoretical concepts, statistical hypothesis testing, distributions, linear algebra, and data modeling in Python.

## Projects Summary

| Project | Description | Technologies |
|---|---|---|
| `MATH_Project_1/` | Analyzing household income distribution and demographic data using descriptive statistics, dispersion measures, skewness, kurtosis, and data visualization. | Python, Jupyter Notebook, Pandas, Seaborn |
| `MATH_project_2/` | Expectation Decider project applying probability theory (empirical vs. theoretical probability, random variables, conditional probability) to predict student pass/fail performance. | Python, Jupyter Notebook, Pandas, SciPy |
| `MATH_project_3/` | Health data analysis utilizing inferential statistics, hypothesis testing (t-test, Chi-Square, ANOVA), confidence intervals, and p-value evaluation. | Python, Jupyter Notebook, Pandas, SciPy |
| `MATH_project_4/` | Transaction data analysis using probability distributions (Bernoulli, Binomial, Log-Normal, Power Law, Poisson), Q-Q plots, and Box-Cox transformations. | Python, Jupyter Notebook, SciPy, Matplotlib |
| `MATH_project_5/` | Student performance analysis applying linear algebra concepts, including vector norms, matrix operations, LU decomposition, SVD, PCA, and LDA. | Python, Jupyter Notebook, NumPy, Scikit-Learn |
| `MATH_PRACTICAL_EXAM/` | Mathematics and advanced statistics exam featuring theoretical explanations and practical Jupyter notebook analysis on 5,000 student score records. | Python, Jupyter Notebook, Statistics |
