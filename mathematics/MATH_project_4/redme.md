# Probability Distributions & Spread Analysis

## Project Title

Probability Distributions and Statistical Analysis on Transaction Data

## Project Objective

The objective of this project is to analyze transaction data using probability distributions and statistical techniques. The project demonstrates how different distributions can model real-world business transactions and help identify patterns, trends, and anomalies.

---

## Dataset Information

**Dataset Name:** spread_locator.csv

The dataset contains transaction-related information including:

* Transaction ID
* Customer ID
* Transaction Amount
* Transaction Date
* Transaction Count
* Region
* Transaction Status

---

## Part A – Theoretical Foundation

The following statistical concepts are covered:

1. Statistical Distribution
2. Q-Q Plot
3. Discrete vs Continuous Distributions
4. Bernoulli Distribution
5. Binomial Distribution
6. Log-Normal Distribution
7. Power Law Distribution
8. Box-Cox Transformation
9. Poisson Distribution
10. Z-Score Probability
11. PDF and CDF

---

## Part B – Practical Implementation

The notebook performs:

### 1. Bernoulli Distribution

Analysis of transaction success and failure probabilities.

### 2. Binomial Distribution

Modeling the number of successful transactions.

### 3. Poisson Distribution

Modeling transaction occurrences over time.

### 4. Log-Normal Distribution

Fitting transaction amount data to a log-normal distribution.

### 5. Power Law Distribution

Analyzing heavy-tailed behavior in transaction amounts.

### 6. Q-Q Plot Analysis

Checking distribution fit visually.

### 7. Box-Cox Transformation

Reducing skewness and improving normality.

### 8. Z-Score Analysis

Identifying outliers and unusual transactions.

### 9. Probability Estimation

Calculating probability of transaction amounts exceeding a threshold.

### 10. PDF and CDF Visualization

Visual representation of probability distributions.
