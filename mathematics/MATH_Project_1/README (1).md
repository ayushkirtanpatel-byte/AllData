# Analyzing Income Distribution and Household Demographics

## Project Overview
This project focuses on analyzing household demographic and income data using Python.  
The analysis includes descriptive statistics, data distribution analysis, measures of dispersion, skewness, kurtosis, and data visualization.

The project is developed as part of a statistics and data analytics practical assignment.

---

## Objective
The main objective of this project is to:

- Analyze household income distribution
- Study demographic information
- Understand numerical and categorical data
- Calculate descriptive statistics
- Visualize data distributions
- Interpret skewness and kurtosis

---

## Dataset Information

The dataset contains **200 household records** with the following columns:

| Column Name | Data Type | Description |
|---|---|---|
| Household_ID | Categorical | Unique household identifier |
| Age_of_Household_Head | Numerical | Age of household head |
| Household_Income | Numerical | Monthly household income |
| Education_Level | Categorical | Education qualification |
| Family_Size | Numerical | Number of family members |
| Owns_House | Categorical | Yes / No |
| Urban_Rural | Categorical | Urban or Rural |

## Key Findings

- Higher education levels generally have higher income.
- Income distribution is moderately spread.
- Urban households tend to have higher income concentration.
- The dataset shows near-normal distribution.
- Skewness and kurtosis help understand data shape and spread.
