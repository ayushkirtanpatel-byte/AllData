# 🎓 Student Performance & Behavior Analytics Dashboard

## 📌 Project Overview

This Power BI dashboard analyzes: - Academic performance (scores) -
Attendance trends - Student behavior patterns

Designed for interactive insights across Class, Section, Subject, and
Term.

------------------------------------------------------------------------

## 📂 Dataset Used

-   Students.csv → Student details
-   Scores.csv → Subject-wise scores
-   Attendance.csv → Daily attendance
-   Behavior.csv → Behavior logs

------------------------------------------------------------------------

## 🧠 Key Features

### 📊 KPIs

-   Total Students
-   Average Score
-   Attendance %
-   \% Score

### 📈 Visualizations

-   Bar Chart → Subject-wise performance
-   Line Chart → Performance trend over terms
-   Donut Chart → Behavior distribution
-   Table → Student-wise performance

### 🎛 Interactivity

-   Slicers → Class, Section, Subject, Term
-   Drillthrough → Student-level insights
-   Bookmark navigation → Academic & Behavior view

------------------------------------------------------------------------

## 🎨 Design Highlights

-   Clean blue gradient background
-   Card-based layout
-   Minimal & professional UI
-   Conditional formatting for performance

------------------------------------------------------------------------

## ⚠️ Insights

-   Science shows highest performance
