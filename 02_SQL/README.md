# 02_SQL — SQL Database & Querying Projects

This directory contains SQL scripts, relational database schemas, DDL/DML scripts, data cleaning/transformation routines, and practice assignments using MySQL and standard SQL syntax.

## Projects Summary

| Project | Description | Technologies |
|---|---|---|
| `data_digger project.sql` | Relational database schema creation (`CLIENT` table) with DDL statements, primary keys, and data insertion queries. | SQL, MySQL |
| `data_transform.sql` | SQL data cleaning script featuring customer database creation, string trimming, email validation, and data transformation operations. | SQL, MySQL |
| `final_project.sql` | Relational database setup modeling student course enrollments, courses, and instructors with foreign key relationships. | SQL, MySQL |
| `PRCTICAL/` | Smart Library Management System implementation covering CRUD operations, multi-table JOINs, subqueries, aggregations, window functions, and CASE expressions. | SQL, MySQL |
