# Smart Library Management System

## Overview
A MySQL practical project implementing a Smart Library Management System with relational tables, CRUD operations, joins, subqueries, aggregations, window functions, and CASE expressions.

## Database Structure
- Authors
- Books
- Members
- Transactions

## Features
- Book and author management
- Member registration and tracking
- Borrow and return transactions
- Fine calculation
- Membership status analysis
- Most-borrowed book analysis
- Category-wise analysis

## Technologies
- MySQL
- SQL
- MySQL Workbench

## Files
- `practical exam.sql` — SQL practical/exam queries
- `PRCTICAL_RADME.txt` — project notes

## How to Run
Open MySQL Workbench, create a SQL query window, and execute `practical exam.sql`.
