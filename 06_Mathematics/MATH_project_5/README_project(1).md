# Student Performance Analysis Using Linear Algebra

## Project Overview

This project applies Linear Algebra concepts to analyze student performance data across seven subjects.

The dataset contains 220 students categorized as:

* Above Average
* Below Average

The project demonstrates practical applications of vectors, matrices, matrix decompositions, eigenvalues, PCA, and LDA using Python and Jupyter Notebook.

---

## Dataset Features

* StudentID
* StudentName
* Category
* Math
* Science
* English
* History
* Computer_Science
* Physics
* Chemistry
* Average

---

## Objectives

* Represent student scores as vectors.
* Perform norm calculations.
* Compute dot products and cross products.
* Calculate vector projections.
* Apply matrix operations.
* Compute determinants and matrix inverses.
* Analyze covariance matrices.
* Calculate eigenvalues and eigenvectors.
* Perform LU Decomposition.
* Perform Singular Value Decomposition (SVD).
* Apply Principal Component Analysis (PCA).
* Apply Linear Discriminant Analysis (LDA).
