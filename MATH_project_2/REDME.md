# Expectation Decider Project

## Project Overview

The Expectation Decider Project is a probability and statistics based project developed using Python in Jupyter Notebook.

This project analyzes student performance data and predicts whether a student will pass or fail in the final exam based on different factors.

---

# Dataset Features

The dataset contains the following columns:

- study_hours
- attendance
- group_discussion
- previous_test_score
- final_exam_pass

Total Records: 150
