# 04_PowerBI — Business Intelligence & Dashboard Projects

This directory contains Power BI projects (`.pbix` files), supporting data models, DAX measures, and documentation for business intelligence and data visualization dashboards.

## Projects Summary

| Project | Description | Technologies |
|---|---|---|
| `PROJECT_1/` | Multi-month sales report combining monthly Excel workbooks via Power Query, integrating Web API HTML tables, and mapping employee datasets. | Power BI, Power Query, Excel |
| `PowerBi PROJECT_2/` | Sales & Returns star schema data model connecting sales facts, returns facts, customer dimensions, product dimensions, region dimensions, and date dimensions. | Power BI, DAX, Excel |
| `powerBi PROJECT_3/` | Interactive sales performance dashboard using DAX measures, dimension relationships, and multi-table data modeling. | Power BI, DAX, Excel |
| `Final_Project/` | Executive sales analytics dashboard delivering KPI cards, return rate analysis, customer segmentation, and regional trends via star schema architecture. | Power BI, DAX, Star Schema |
| `Ayush_PRCTICAL EXAM/` | Student performance and behavior analytics dashboard visualizing academic scores, attendance trends, and behavioral patterns. | Power BI, Excel |
